# v0.0.1 — Beans

## Goal
Prove the complete emotional and mechanical loop with one Mothling.

## Acceptance criteria
- [ ] Portrait mobile project launches.
- [ ] Player can enter Whispering Woods.
- [ ] Lure Site supports a limited number of placed objects.
- [ ] Placed objects produce hidden environment tags.
- [ ] Observation chooses visitors from attraction scores.
- [ ] Trail Cam produces readable events/evidence.
- [ ] Mothling progresses from unknown evidence to discovered species.
- [ ] A wild Mothling persists as the same individual across repeat visits.
- [ ] Trust persists between sessions.
- [ ] Bonded Mothling can be invited home.
- [ ] Player can name the adopted Mothling.
- [ ] Adopted Mothling appears in Sanctuary.
- [ ] Sanctuary lamp triggers its special interaction.
- [ ] **Warm Glow** Moment is permanently recorded.
- [ ] Local save/load survives reopening the game.

## Out of scope
Accounts, cloud saves, multiplayer, monetization, combat, breeding, procedural maps, large inventories, live events, and polished final art.

## Definition of success
After bringing the Mothling home, the player wants to return to Whispering Woods to find the next creature.
